⌚ Collaboration Rolex X Inception : Le Cube Immersif
Bienvenue dans cette expérience de réalité virtuelle unique, fusionnant l'excellence horlogère de Rolex et l'univers onirique du film culte Inception.

🎯 Le Concept
Dans le cadre de ce projet, j'ai conçu un "CUBE IMMERSIF" : une vitrine virtuelle de 4m x 4m x 4m. Cette capsule exclusive explore la frontière entre le rêve et la réalité, accessible aussi bien sur navigateur qu'avec un casque VR.

La Marque : Rolex (Précision, héritage, luxe).

L'Œuvre : Inception (Architecture mentale, temps, secrets enfouis).

🕵️ Le Défi (Tips)
L'expérience ne s'arrête pas à la simple observation. Pour débloquer l'intégralité de l'immersion :

Objectif : Localiser et déverrouiller le coffre secret du père de Fisher.

Indices : Soyez attentifs à votre environnement, le code est dissimulé quelque part dans le cube.

Recommandation : 🎧 Activez le son pour une immersion totale.
